## Đề bài

Phân tích hệ thống quản lý nhân sự cho công ty sơn Đông Á: tuyển dụng, thử việc, ký hợp đồng, bảo hiểm, quyết định lương/chức vụ, phân công ca, chấm công, phụ trội, tính lương, khen thưởng và kỷ luật.

1. Mô tả hoạt động nghiệp vụ
2. Tác nhân
3. Yêu cầu hệ thống (chức năng)
4. Quy tắc nghiệp vụ
5. Yêu cầu phi chức năng
6. Phân tích: phân rã use case, sơ đồ lớp, sơ đồ trạng thái, sơ đồ tuần tự, thiết kế CSDL
